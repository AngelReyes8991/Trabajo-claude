vistos y promedio de minutos por reproduccion. Utilizar INNER JOIN,
COUNT, SUM, AVG y GROUP BY. Mostrar el promedio con dos decimales.

Respuesta:

IF OBJECT_ID('ReporteConsumoUsuarios', 'U') IS NOT NULL
BEGIN
    DROP TABLE ReporteConsumoUsuarios;
END;
GO

SELECT
    u.UsuarioID,
    u.Nombre,
    u.Pais,
    COUNT(r.ReproduccionID) AS CantidadReproducciones,
    SUM(r.MinutosVistos) AS TotalMinutosVistos,
    CAST(AVG(CAST(r.MinutosVistos AS DECIMAL(10,2))) AS DECIMAL(10,2)) AS PromedioMinutos
INTO ReporteConsumoUsuarios
FROM Usuarios u
INNER JOIN Reproducciones r
    ON u.UsuarioID = r.UsuarioID
WHERE u.Estado = 'Activo'
GROUP BY
    u.UsuarioID,
    u.Nombre,
    u.Pais;
GO

SELECT *
FROM ReporteConsumoUsuarios
ORDER BY TotalMinutosVistos DESC;
GO

Enunciado:
Implementar dos transacciones sobre la tabla Planes. Primera: incrementar
en 20% los precios de los planes con 2 o mas pantallas y deshacer los

el precio del plan Premium y confirmar mediante COMMIT. Mostrar los

Respuesta:

-- TRANSACCION 1: incremento del 20% con ROLLBACK

SELECT
    'ANTES DE LA TRANSACCION 1' AS Momento,
    PlanID,
    NombrePlan,
    CantidadPantallas,
    Precio
FROM Planes
ORDER BY PlanID;
GO

BEGIN TRANSACTION;

UPDATE Planes
SET Precio = Precio * 1.20
WHERE CantidadPantallas >= 2;

SELECT
    'DENTRO DE LA TRANSACCION 1' AS Momento,
    PlanID,
    NombrePlan,
    CantidadPantallas,
    Precio
FROM Planes
ORDER BY PlanID;

ROLLBACK;
GO

SELECT
    'DESPUES DEL ROLLBACK' AS Momento,
    PlanID,
    NombrePlan,
    CantidadPantallas,
    Precio
FROM Planes
ORDER BY PlanID;

-- TRANSACCION 2: incremento de 5 unidades monetarias con COMMIT

SELECT
    'ANTES DE LA TRANSACCION 2' AS Momento,
    PlanID,
    NombrePlan,
    CantidadPantallas,
    Precio
FROM Planes
WHERE NombrePlan = 'Premium';
GO

BEGIN TRANSACTION;

UPDATE Planes
SET Precio = Precio + 5
WHERE NombrePlan = 'Premium';

COMMIT;
GO

SELECT
    'DESPUES DEL COMMIT' AS Momento,
    PlanID,
    NombrePlan,
    CantidadPantallas,
    Precio

Enunciado:
Crear una vista llamada vw_EstadisticasUsuarios que muestre UsuarioID,
Nombre, Pais, Estado, cantidad de reproducciones, total de minutos vistos
y promedio de minutos por reproduccion. Utilizar LEFT JOIN, COUNT, SUM,
AVG, GROUP BY e ISNULL, incluyendo usuarios sin reproducciones con valores
de cero. Consultar la vista mostrando unicamente usuarios con mas de 100
minutos vistos, ordenados de mayor a menor.

Respuesta:

CREATE OR ALTER VIEW vw_EstadisticasUsuarios
AS
SELECT
    u.UsuarioID,
    u.Nombre,
    u.Pais,
    u.Estado,
    COUNT(r.ReproduccionID) AS CantidadReproducciones,
    ISNULL(SUM(r.MinutosVistos), 0) AS TotalMinutosVistos,
    ISNULL(CAST(AVG(CAST(r.MinutosVistos AS DECIMAL(10,2))) AS DECIMAL(10,2)), 0) AS PromedioMinutos
FROM Usuarios u
LEFT JOIN Reproducciones r
    ON u.UsuarioID = r.UsuarioID
GROUP BY
    u.UsuarioID,
    u.Nombre,
    u.Pais,
    u.Estado;
GO

SELECT *
FROM vw_EstadisticasUsuarios
WHERE TotalMinutosVistos > 100
ORDER BY TotalMinutosVistos DESC;
GO

PREGUNTA 8 (2 puntos)
============================================================

Enunciado:
Crear una vista llamada vw_ContenidosSuperioresPromedio que muestre los
contenidos cuyo total de minutos vistos supere el promedio de minutos
acumulados por contenido con reproducciones. Mostrar ContenidoID, Titulo,
Tipo, Categoria, cantidad de reproducciones y total de minutos vistos.
Utilizar INNER JOIN, COUNT, SUM, GROUP BY y una subconsulta para calcular
el promedio correspondiente. Consultar la vista ordenando por total de
minutos vistos de mayor a menor.

Respuesta:

CREATE OR ALTER VIEW vw_ContenidosSuperioresPromedio
AS
SELECT
    c.ContenidoID,
    c.Titulo,
    c.Tipo,
    c.Categoria,
    COUNT(r.ReproduccionID) AS CantidadReproducciones,
    SUM(r.MinutosVistos) AS TotalMinutosVistos
FROM Contenidos c
INNER JOIN Reproducciones r
    ON c.ContenidoID = r.ContenidoID
GROUP BY
    c.ContenidoID,
    c.Titulo,
    c.Tipo,
    c.Categoria
HAVING SUM(r.MinutosVistos) > (
    SELECT AVG(CAST(t.TotalMinutos AS DECIMAL(10,2)))
    FROM (
        SELECT
            ContenidoID,
            SUM(MinutosVistos) AS TotalMinutos
        FROM Reproducciones
        GROUP BY ContenidoID
    ) AS t
);
GO

SELECT *
FROM vw_ContenidosSuperioresPromedio
ORDER BY TotalMinutosVistos DESC;
GO

      AND object_id = OBJECT_ID('Contenidos')
